# 🏨 StayNext

StayNext is a full-stack hotel and vacation rental booking platform built with the MERN-related Node.js ecosystem. It allows users to explore, create, edit, and manage property listings with secure authentication, image uploads, and a review system. The application follows the MVC architecture and provides a responsive, user-friendly experience.

## ✨ Features

- User Authentication & Authorization using Passport.js
- Create, Read, Update & Delete (CRUD) property listings
- Upload property images using Cloudinary & Multer
- Add and delete reviews with ratings
- Listing ownership and review authorization
- Server-side validation using Joi
- Flash messages for user feedback
- Centralized error handling
- Responsive UI with Bootstrap
- RESTful routing following MVC architecture

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/mdzahidalamgehu1/stayNext.git
```

### Navigate to the project

```bash
cd stayNext
```

### Install dependencies

```bash
npm install
```
### Start the application

```bash
npm start
```

Visit:

```
http://localhost:8080
```
